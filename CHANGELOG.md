# Changelog

## 2.0.0 — 2026-11-12

- Rebuilt cTool as a Chrome and Edge Manifest V3 extension with a popup editor and expanded workbench.
- Added a canonical editable request model, safe cURL import/export, environment variables, Basic and Bearer authentication, JSON/text/forms/multipart bodies, and explicit file selection.
- Added a serialized background request lifecycle, scoped temporary Cookie and restricted-header rules, cancellation, timeouts, response limits, and safe text rendering.
- Added local IndexedDB history, saved drafts, favorites, environment settings, privacy mode, backup validation, and legacy `curlHistory` migration.
- Added bilingual interface, system/light/dark themes, MIT license, privacy and compatibility documents, Playwright checks, and an allowlisted ZIP package.
