## 工作概述

基于用户批准的 cTool 2.0 方案，将 MV3 原型扩展为本地优先的 Chrome/Edge cURL 调试插件，覆盖请求建模、导入/执行/响应、历史与收藏、环境变量、旧数据迁移、隐私控制、测试、打包和 GitHub 交付。实施分支为 codex/mature-extension。

## 范围与验收

- **需求**：统一 RequestDraft 驱动请求编辑和执行；支持常见 DevTools Bash/CMD cURL、重复有序查询、Basic/Bearer、JSON/文本/URL 编码/multipart；安全查看和下载状态、头、正文。
- **验收标准**：发送使用当前编辑模型；非法命令、缺少环境变量、认证冲突和不支持的网络选项明确阻止；绝不执行 shell 文本。

## 风险
